# Quant Projects

个人量化研究与学习项目的目录。每个项目是一个独立的仓库，点击名称进入。

| 项目 | 内容 |
|---|---|
| [china_futures_replication](https://github.com/aslongasyouhaha/china_futures_replication) | 在中国期货数据（2005–2026）上复现 17 篇正式发表的金融论文和 1 篇工作论文，检验 carry、动量、价值、时间序列动量、波动率预测等结论在中国是否成立，并汇总成一份中国期货市场的全貌梳理 |
| [factors_framework](https://github.com/aslongasyouhaha/factors_framework) | 美股横截面因子研究：每篇论文一个复现项目，共用同一套数据处理流程（CRSP、Compustat）和统一的回测框架 factorlab |
| [xtx_vol_surface](https://github.com/aslongasyouhaha/xtx_vol_surface) | 在 SPXW 期权数据上实现 SANOS/XTX 的期权曲面构造方法，把筛选后的报价拟合成平滑、无套利的看涨期权价格曲面 |
| [Monte_Carlo](https://github.com/aslongasyouhaha/Monte_Carlo) | 蒙特卡洛方法练习：随机数生成与拒绝抽样、Cholesky 分解、别名法与信用评级迁移、控制变量与重要性抽样、Broadie–Glasserman 的 Greeks 估计、最小二乘蒙特卡洛（LSM） |

`Monte_Carlo/` 以子模块形式收录在本仓库中。
